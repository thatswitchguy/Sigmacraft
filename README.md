# Sigmacraft

This is a small, Minecraft-inspired game I made. It is made for low-end computers (School Chromebooks), as it optimises render distance to around 10 blocks (in your sight), and anything not directly in your view, isn't rendered. This is a JAVASCRIPT project, as the percentage of typecript is all in the pre-installed VS Code Agent files - and do not affect the game at all.

Published link » <kbd>[Here](https://sigmacraft.onrender.com)</kbd>


## Features

- Optimised render distance to around 10 blocks (in your sight only)
- F+5 Camera toggle
- Crafting
- Inventory
- Dev mode (in-game data [textures, block names, tools etc.] editor) with password
- Multiplayer
- Seed gen (unique, but not customisable (can't put one in like a set seed)
- Sneaking (player movement model, not yet done)
- Trees
- Health system

## Controls

- WASD - Move
- Space - Jump
- Left Click - Mine
- Right Click - Place
- Shift (Hold) - Sneak
- [>] - Dev mode
- esc - Pause
- Q - Drop Item
- Shift + Q - Drop Stack
- E - Inventory
- Click once on item slot in Inventory - Pick up/hold
- Click down again on item slot - Put down/drop
- Shift+Click down on item slot while holding a stack of items more than 2 - Place one from stack
